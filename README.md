# Zecrow

Zecrow is a managed private escrow experience for real-world commerce using shielded Zcash payments.

## Development

```bash
npm install
npm run dev
```

## Current scope
The first milestone establishes the Rixor-inspired ribbon background and navbar only. The hero section, auth, escrow state machine, and Zcash integration are not implemented yet. See [HANDOFF.md](./HANDOFF.md) for the current implementation status and continuation notes.
